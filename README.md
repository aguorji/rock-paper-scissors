# Rock Paper Scissors

A browser version of the classic game: play against the computer, first to 5 wins.

**Live demo:** https://aguorji.github.io/rock-paper-scissors/

## Features

- Click a move or use the keyboard: **R**, **P**, **S**
- Live scoreboard with each player's pick
- Round-by-round history
- End-of-game result with a "Play again" option
- Responsive, accessible (screen-reader announcements, focus styles, reduced-motion support)

## Built with

HTML, CSS and vanilla JavaScript — no frameworks.

Started as a console game for [The Odin Project](https://www.theodinproject.com/) and
later rebuilt with a full user interface.

## Run locally

Open `index.html` in any browser.
